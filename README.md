## 🗓️ Day-by-Day Syllabus

### Day 1: Programming Fundamentals
- **Core Topics:** Compilation vs. Interpretation, Standard I/O (`cin`/`cout`, `input()`), Variables, Static vs. Dynamic Typing.
- **Key Concepts:** Integer division vs. modulus, memory representation, dynamic inputs.

### Day 2: Control Flow & Loops
- **Core Topics:** Conditional branching (`if-else`, `elif`), Truthy/Falsy values, Logical operators (`&&`, `||`).
- **Key Concepts:** Iteration with `for` and `while`, Python `range()` mechanics (start, stop, step), accumulator patterns.

### Day 3: Functions & DSA Signatures
- **Core Topics:** Modular programming, parameters vs. arguments, return types, function call stacks.
- **Key Concepts:** Reading LeetCode/GFG function templates, parameter passing, handling base/edge cases.

### Day 4: Arrays & Linked Lists
- **Core Topics:** Contiguous vs. non-contiguous memory layouts, 0-based indexing, node-pointer mechanics.
- **Key Concepts:** Time complexity trade-offs ($\mathcal{O}(1)$ random access vs. $\mathcal{O}(1)$ insertion/deletion).
